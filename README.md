📌 Sobre o Projeto

Dashboard comercial desenvolvido no Power BI para analisar a performance de vendas sob diferentes perspectivas, combinando visualizações interativas, indicadores de vendas e análise geográfica.

Desenvolvido durante o curso Microsoft Power BI Para Business Intelligence e Data Science, da Data Science Academy (DSA).

📑 Páginas do Dashboard

1. Índice de Navegação: página para navegar entre as seções do dashboard.
2. Visão Geral de Vendas:
   - Narrativa inteligente com resumo dos principais indicadores e comparações.
   - Valor de vendas por segmento (gráfico de pizza).
   - Valor de vendas por fabricante (gráfico de colunas agrupadas).
   - Valor de vendas por categoria (gráfico de funil).
3. Principais Influenciadores: análise dos fatores associados ao valor de vendas e da relação entre desempenho, segmentos e categorias.
4. Vendas por Loja e Categoria: gráfico de linhas comparando o valor de vendas entre categorias, com as lojas na legenda.
5. Análise Geográfica de Vendas:
   - Mapa de vendas por estado, com vendedores na legenda.
   - Tamanho das bolhas proporcional ao total de vendas.
   - Filtro para valores de vendas acima de 30.000.

🛠️ Ferramentas

- Power BI: desenvolvimento do dashboard e visualização de dados
- Power Query: preparação e transformação dos dados
- DAX: criação de medidas e cálculos
- Excel: base de dados

🎯 Objetivos

- Explorar o desempenho de vendas por fabricante, segmento e categoria.
- Comparar resultados entre lojas.
- Analisar a distribuição geográfica das vendas.
- Praticar técnicas de Business Intelligence e visualização interativa.

📌 About the Project

Commercial dashboard built in Power BI to analyze sales performance from different perspectives, combining interactive visualizations, sales indicators, and geographic analysis.

Developed during the Microsoft Power BI for Business Intelligence and Data Science course by Data Science Academy (DSA).

📑 Dashboard Pages

1. Navigation Index: page to navigate between dashboard sections.
2. Sales Overview:
   - Smart narrative summarizing key figures and comparisons.
   - Sales value by segment (pie chart).
   - Sales value by manufacturer (clustered column chart).
   - Sales value by category (funnel chart).
3. Key Influencers: analysis of factors associated with sales value and the relationship between performance, segments, and categories.
4. Sales by Store and Category: line chart comparing sales value across categories, with stores in the legend.
5. Geographic Sales Analysis:
   - Map of sales by state, with salespeople in the legend.
   - Bubble size proportional to total sales.
   - Filter for sales values above 30,000.

🛠️ Tools

- Power BI: dashboard development and data visualization
- Power Query: data preparation and transformation
- DAX: measures and calculations
- Excel: data source

🎯 Goals

- Explore sales performance by manufacturer, segment, and category.
- Compare results across stores.
- Analyze the geographic distribution of sales.
- Practice Business Intelligence techniques and interactive visualization.
